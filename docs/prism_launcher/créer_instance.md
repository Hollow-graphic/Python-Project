# Création d'une instance

Dans le menu de prism launcher, appuyé sur le boutton "ajouter une instance"

![create_instance_button](/docs/prism_launcher/img/create_instance_button.png)

dans la nouvelle fenêtre tu peux modifier les différent paramètre de la fenètre <br>
en haut de la fênetre tu peux modifier le nom dans la zone de text et l'icone en appuyant l'icone de block de terre


![create_instance_window](/docs/prism_launcher/img/create_instance_window.png)

1. Boutton pour confirmer la création après modifier tout les paramètre ou si tu veux juste joué en vanilla
2. Sélectionner si tu veux un minecraft moddé personalisé
3. Sélectionnes si tu veux installer un modpack
     - __curseforge__: pour installer des modpack qui modifie le jeu comme ajouter des items
     - __modrinth__: pour installer des modpack qui améliore l'experience de jeu sans ajouter d'item (qui peut donc rejoindre des server vanilla)
4. Si tu as sélectionné modpack personalisé, tu dois sélectionné une version:
     - 26.1.2 (ou celle qui est tout en haut) pour jouer dans la dernière version de minecraft
       puis les version pour jouer en modder:
     - 1.21.1 (récommandé pour mod récent)
     - 1.20.1 (récommandé)
     - 1.19.2
     - 1.18.2
     - 1.16.5
     - 1.12.2
     - 1.7.10
5. Puis tu dois sélectionner le mod loader, pour faire simple:
     - forge = modpack qui ajoute des items
     - fabric = modpack qui améliore l'experience
       (c'est beaucoup plus complexe mais pour un modpack personalizé c'est tout que tu doit savoir)
       
Après avoir tout sélectioner tu peux cliqué sur le boutton OK ou 1 sur l'image <br>
le modpack devrait maintenant s'afficher dans le menu principale <br>
si tu veux le modifier / ajouter des mods tu peux suivre le tuto [Ajouter des Mods](https://github.com/Hollow-graphic/Python-Project/blob/main/docs/prism_launcher/ajouter_mod.md)
